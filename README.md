# 🌿 Lavr

**Конструктор наградных документов**

![Version](https://img.shields.io/badge/version-1.0.0-blue)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE.md)

Lavr (от лат. *laurus* — лавр, символ победы и признания) — это лёгкий веб-инструмент для создания и оформления наградных документов без установки дополнительного ПО.

## ✨ Возможности

- 📄 **4 типа документов**: благодарственное письмо, почётная грамота, диплом, сертификат
- 🖼️ **Загрузка своих шаблонов** (drag & drop)
- ✏️ **Редактирование текста** двойным кликом
- 🖱️ **Перетаскивание элементов** мышью
- 📏 **Линейки в миллиметрах** с точной привязкой
- 🎯 **Направляющие** для выравнивания по центру и краям
- 📐 **Формат А4**: книжная и альбомная ориентация
- 📥 **Экспорт в PDF** высокого качества
- 🖨️ **Печать** напрямую из браузера

## 🚀 Быстрый старт

1. Откройте `index.html` в любом современном браузере
2. Загрузите изображение шаблона
3. Добавьте текстовые элементы кнопками на панели
4. Перетащите текст в нужное место
5. Нажмите «Скачать PDF»
